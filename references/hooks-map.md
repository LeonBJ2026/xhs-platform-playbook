# 引流钩子图谱 — 第三方玩法 × 官方红线对照

> 用途：**知彼，不是照做**。识别别人怎么做、知道为什么会被罚，比学会怎么做更有价值。
> 来源：公开的第三方运营脑图汇总；对照基准：小红书《交易导流违规管理细则》（2026-09-18 修订）及抖音社区规范。

## 抖音

| 钩子手法 | 在新规下的状态 |
|---|---|
| 粉丝群：有流量后开粉丝群、设入群门槛 | ✅ 站内动作，可行——但群内导站外仍违规 |
| 简介 / 头像 / 背景图三件套做引导 | 🔴 高风险——属"账号信息导流"，明确打击项 |
| 评论区发资料包福利，引导私信小助理领取 | 🔴 高风险——"评论区+私信"正是重点监控链路 |
| 抖音小店：购前点客服、购后跳转外链或发短信 | 🟡 电商场景可用——不开店则不适用 |

## 小红书

| 钩子手法 | 在新规下的状态 |
|---|---|
| 私信回复：私信提示添加、发二维码图片 | 🔴 直接违规——私信已被细则明确覆盖，图片植入二维码属认定情形 |
| 评论区：引导领免费资料，把用户引入私域 | 🔴 直接违规——诱导互动+导流双重命中 |
| 账号简介：文字放微信号 / 邮箱 / 微博号 | 🔴 直接违规——简介是细则点名的第一位置 |
| 笔记置顶：专门编辑一篇含账号信息的笔记 | 🔴 直接违规——笔记本体导流，查得最严 |
| 日签组合：主页日签轮播图嵌微信号 | 🔴 直接违规——属"图片植入"认定情形，且主页全量可见 |

## 电商平台（与本技能主要受众关系不大，备查）

外呼电话发券、客服话术加微信、店铺首页优惠字样、包裹内二维码卡片——开店业务才涉及。

## 微信渠道（生态内合法，但解决不了跨平台那一步）

搜一搜品牌词、公众号菜单栏/自动回复/图文/广告/话题标签、小程序客服、视频号简介+私信+短视频+标签、私聊群聊触达、小程序广告、朋友圈 # 标签、视频号直播放二维码——全部合法，但前提是流量已经在微信里；**从站外把人带进微信这一步，恰恰是各平台新规封死的地方**。

## 结论

1. 灰色钩子的处罚是批量的、滞后的，不是不罚。看到同行在用，不要跟。
2. 合规转化链路只有一条主线：**内容埋"评论区置顶关键词" → 置顶评论站内给答案 → 用户主动私信 → 私信内正常沟通**。被动响应不违规，主动要联系方式违规。
3. 判断一个"新钩子"能不能用，先问三个问题：位置在不在细则列举范围内？有没有出现站外联系方式或其变体？是用户主动还是你主动？三问有一个答不上来，就别用。
