# 发布前检查表 + 限流排查 + 起号六步展开

## 一、发布前 8+3 项自检（每条必过，不过不发）

### 合规闸（先过这 3 项，顺序不能反）

- [ ] ⑨ 全文无站外联系方式 / 谐音暗号 / 二维码 / 水印（含昵称、简介、图片角落）
- [ ] ⑩ 涉商业合作（收钱 / 免单 / 置换）已走蒲公英报备并打"广告"标
- [ ] ⑪ 用过 AI 的图/音已标注；出镜人物已获书面授权

### 算法与质量自检（8 项）

- [ ] 1. 标题前 8 字含"地点/场景 + 动作/结果"
- [ ] 2. 正文首段出现核心关键词
- [ ] 3. 结尾埋了 1 个**具体可答**的提问（不是"你们觉得呢？"）
- [ ] 4. 给了关注理由：固定栏目名 + 期数 + 下期预告
- [ ] 5. 封面原创实拍，文字主体在上半部，底部留 15–20% 安全区（会被信息流标题压住）
- [ ] 6. 图片统一 3:4（1080×1440）、单图 ≤20MB、≤18 张；同篇内比例统一
- [ ] 7. 有可被转发的实体物（清单 / 路线表 / 时段表）
- [ ] 8. 与最近 2 条不同场景或不同角度（同机位不连发 3 条以上）

### 发布规格速查（硬性）

| 项 | 规格 |
|---|---|
| 图文 | 标题 ≤20 字；正文 ≤1000 字；图片 ≤18 张；单图 ≤20MB；3:4（1080×1440） |
| 封面 | 首图即封面；文字上半部；底部 15–20% 安全区 |
| 视频 | 9:16（1080×1920）；≤3 分钟；MP4；8–12Mbps |
| 水印 | 不带任何他平台水印；双平台分发各自导出 |

## 二、数据差先查三因（〔经验〕，比改稿优先级高）

| 症状 | 先查 |
|---|---|
| 点击率低 | 封面与标题 |
| 互动低 | 内容没共鸣 |
| 完播低 | 内容太散、没抓核心 |

## 三、限流排查流程

连续 3 条数据断崖时的排查顺序：

1. **停发 1–2 天**，不硬发。
2. 查违规：站内通知、笔记状态（是否仅自己可见）、账号违规记录。
3. 查红线：对照 `red-lines.md` 五条逐条过最近内容（尤其是谐音、图片角落、私信自动回复）。
4. 查内容：是否套模板、是否同机位连发、是否 AI 直出未标注。
5. 查选题：回到定位卡，最近内容是否偏离"关注理由"。
6. 排除以上后才改封面标题或换选题；改稿用隐藏重发，单日删笔记 ≤3 篇。

## 四、起号六步（可直接当开工顺序）

1. **定位**：想做什么 / 适合什么 / 能做什么 → 方向可调、核心目标不变。
2. **对标**：找对标账号越多越好；同时一句话说清"关注我能得到什么"——不能自嗨。
3. **熟规则**：先读社区公约，再看近 7 天与 30 天账号数据（需专业号），必要时走人工客服。
4. **选题**：用户视角，实用 / 信息 / 情绪 / 决策价值**至少占一种**；内容做到有趣 / 有用 / 有料 / 有力至少一种。
5. **拆解**：抄对标的是"结构、钩子、节奏"，**不抄具体内容**。
6. **数据差先查三因**：见上表。

### 配套节奏（〔经验〕）

- 发布频率：每周 3–5 篇，可持续优先；前 30 条按关键词占位做，不赌爆款。
- 发布时间：对准目标人群活跃段；发布后 30–60 分钟保持在线回评论。
- 前 3 秒（视频）：直接给冲突、结果或痛点，不铺垫背景、不问候。
- 前 5 条内容基本决定账号被推给谁——起步期内容要高度聚焦定位。
- 出现高于均值 5–10 倍的一条 → 立即围绕它连发同主题，不换题。

### 封面构图公式（〔经验〕）

- 横版：清晰人物主体 + 简洁一句文案。
- 竖版：真实背景 + 关键文案 + 人物主体；或三分屏 + 数据效果 + 人物主体；或纯色背景 + 关键文案 + 人物主体。

## 五、可信度声明

本文件流程与方向为多来源一致的行业经验；所有具体数字（权重、阈值、池子量级）**无官方来源**，只作自身同比基线。官方规则会更新，涉及处罚 / 申诉 / 报备操作前，回站内规则中心复核最新版。
