# xhs-platform-playbook

**小红书 / 抖音平台规则与流量算法「判断层」AI 技能** —— 发每条内容之前，先让它回答"能不能发、方向对不对"。

适合：用 AI Agent（TRAE / Claude Code / 其他支持 SKILL.md 的智能体）辅助做小红书、抖音内容的创作者和运营。

---

## 这个技能解决什么问题

做自媒体最常踩的坑不是"写得不好"，而是：

- **发出去就违规**：2026-09-18 起小红书《交易导流违规管理细则》修订生效，私信、简介、图片植入、谐音暗号全部纳入导流监控，三次违规可永久关闭权限并连坐关联账号；
- **被"引流钩子教程"带沟里**：第三方教的私信发码、评论区领资料、简介放号等玩法，几乎全部直接违规——这个技能给你一份"钩子 × 红线"对照表，**知彼，但不照做**；
- **把博主截图当平台规则**：曝光池量级、CES 权重、晋级率这些数字互相矛盾且均无官方来源。技能内置三级可信度标签（〔官方〕〔经验〕〔冲突〕）和 8 条口径冲突清单，**流程可用，数字不对外**；
- **发布前没有固定检查动作**：内置 8+3 项自检清单（合规闸 3 项 + 算法质量 8 项），不过不发。

## 能力地图

| 模块 | 内容 |
|---|---|
| 五条平台红线 | 站外引流 / 未报备软广 / AI 内容标注 / 肖像权 / 搬运，每条附官方依据与合规做法 |
| 引流钩子识别 | 第三方常见钩子的违规判定 + 合规转化链路（评论区置顶关键词 → 用户主动私信） |
| 发布规格 | 图文 3:4 / ≤18 张 / ≤20MB；视频 9:16 / ≤3 分钟 / MP4；封面安全区 15–20% |
| 算法方向 | 权重方向（关注 > 评论/转发 > 点赞/收藏）、关键词三层布设、7 天改稿节奏 |
| 发布前自检 | 合规闸 3 项 + 算法质量 8 项，逐条打勾 |
| 起号六步 | 定位 → 对标 → 熟规则 → 选题 → 拆解 → 数据差查三因 |
| 限流排查 | 连续数据断崖时的 6 步排查顺序 |
| 口径冲突清单 | 8 条"数字不能当真"的清单（曝光池、收藏权重、考核周期等） |

详细内容在 `references/` 目录：

- `references/red-lines.md` — 五条红线详版（依据、认定情形、处罚梯度、申诉通道）
- `references/hooks-map.md` — 引流钩子图谱：抖音/小红书/电商/微信四渠道对照
- `references/algorithm-notes.md` — 算法口径整理 + 冲突清单
- `references/checklist.md` — 发布前检查表 + 限流排查 + 起号六步展开

## 安装

把整个 `xhs-platform-playbook` 目录放进你的 Agent 技能目录即可：

```bash
# TRAE（项目级，当前会话即可生效）
.trae/skills/xhs-platform-playbook/

# Claude Code（用户级）
~/.claude/skills/xhs-platform-playbook/
```

或直接克隆到技能目录：

```bash
git clone https://github.com/LeonBJ2026/xhs-platform-playbook.git
```

## 使用

在对话中触发，例如：

- "这条笔记能不能发？"
- "帮我过一遍发布前检查"
- "这个引流动作违规吗？"
- "笔记限流了，帮我排查"

建议把它当作**判断层**，与写作执行层技能（如 xhs-content-skills 类）配套：**两层都过才发**。

可选：在你的项目里放一份《账号定位卡》，把 SKILL.md 第八节的 `_YOUR_ACCOUNT_PROFILE_` 占位符替换成你的定位卡路径，"这条内容符不符合定位"就有据可依。

- 所有量级、比率、权重数字均为第三方口径，**只作自身同比基线，不构成对平台规则的引用或承诺**。
- 本技能不构成法律意见；肖像权、广告法等事项请咨询专业人士。
- 不含"自动发布""批量起号"等玩法；任何自动化链路请自行验证后再用。
